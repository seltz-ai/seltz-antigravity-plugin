# Seltz plugin for Antigravity

Fast and accurate web search for AI agents. The plugin connects Antigravity to the Seltz MCP server and adds two tools:

- `search`: web search with filters for news, companies, people, dates and domains
- `fetch`: reads the full content of web pages as markdown

## Install

```
agy plugin install https://github.com/seltz-ai/seltz-antigravity-plugin
```

You will be asked for your Seltz API key. Create one at https://console.seltz.ai.
